# 🚀 Distributed IoT Sensor Data Compression System

## 📌 Overview
This project demonstrates a **Distributed IoT Data Compression and Transmission System** using **Autoencoders (Deep Learning)**.

The system compresses sensor data on the client side, transmits it efficiently, and reconstructs it on the server side while minimizing data loss.

---

## 🧠 Key Idea
- Use **Autoencoder Neural Network**
- Reduce data size before transmission
- Reconstruct data with minimal error

---

## ⚙️ Architecture

Client ➝ Encoder ➝ Compressed Data ➝ Server ➝ Decoder ➝ Reconstructed Data

## 🔄 Workflow

1. Train autoencoder model  
2. Split into encoder & decoder  
3. Client compresses sensor data  
4. Server reconstructs data  
5. Calculate reconstruction error
